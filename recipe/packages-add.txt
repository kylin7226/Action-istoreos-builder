#      需先在 workflow 里加一步下载到 $IB_DIR/packages/，IB 会自动重建索引
#      （apk mkndx --allow-untrusted），例：ddns-go、luci-app-ddns-go、luci-app-mosdns
#   3. 上游快照仓库（如 https://downloads.immortalwrt.org/snapshots/packages/aarch64_generic/packages/）
#      例：mosdns（dllkids feed 只有 luci 壳，主程序在 ImmortalWrt 快照里）

# RK3588 多媒体内核驱动：
#   kmod-rk_vcodec = RKMPP 视频编解码内核驱动（VPU，生成 /dev/mpp_service）
#   kmod-rga3      = RGA 2D 加速器内核驱动（生成 /dev/rga）
#   只装内核驱动、不装用户态库：容器镜像自带 librockchip_mpp/librga，
#   Docker 透传 /dev/mpp_service、/dev/rga 即可用满 VPU/RGA 硬件。
#   宿主不跑原生 ffmpeg-mpp 转码，故无需 rkmpp/rkrga/ffmpeg-mpp 用户态 apk。
kmod-rk_vcodec
kmod-rga3
